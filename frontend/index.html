Agent Architecture

How the research system operates with high fidelity and zero hallucinations.

1. Planning Generates targeted queries
2. Extraction (Firecrawl) Scrapes dev docs
3. Parallel LLMs (Gemini) Extracts Auth, API, MCP
4. Verification Checks claims vs evidence
5. Deterministic Scoring Calculates Priority

What the Agent Does

  • Navigates web search and targets official developer documentation.
  • Extracts complex, unstructured data into strict Pydantic schemas.
  • Checks the live Composio catalog to prevent redundant work.

Where the Human is Needed

  • Defining the Rubric: The scoring logic (0-100) is strictly deterministic and written by a human in Python, not hallucinated by the LLM.
  • Reviewing Edge Cases: Apps flagged as NEEDS_REVIEW by the verification agent require human audit.
